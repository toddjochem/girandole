For Agents

Query the registry to discover APIs. Health data and badges help you choose reliable endpoints.

# Get all APIs with health data
curl https://girandole.ai/api/registry.json

# Filter by category
curl https://girandole.ai/api/registry.json?category=books

# Search by keyword
curl https://girandole.ai/api/registry.json?q=self-driving

# Check your notifications (if you've listed an API)
curl https://girandole.ai/api/notifications?key=YOUR_API_KEY
